# 📡 Telegram Channel Forwarder Bot

Бот для автоматической пересылки сообщений из нескольких Telegram-каналов/групп в один целевой канал (супергруппу).  
Использует два клиента: **Telethon** (для чтения сообщений от имени вашего аккаунта) и **Aiogram** (для отправки сообщений от имени бота).


## 📌 Возможности

- 🔄 **Мониторинг нескольких источников** – бот отслеживает новые сообщения в указанных чатах и мгновенно пересылает их.
- 📸 **Поддержка медиа** – фото и другие файлы пересылаются вместе с текстом подписи.
- 📝 **Текстовые сообщения** – отправляются с отключённым предпросмотром ссылок.
- 🧩 **Работа с любыми чатами** – поддерживаются каналы, группы, супергруппы (в том числе форумы).
- 📨 **Логирование** – все действия и ошибки записываются в лог и отправляются администратору.
- 🔁 **Автоперезапуск** – бот автоматически перезапускается при критических ошибках.


## 🛠 Технологии

- **Python 3.10+**
- **Aiogram 3.x** – отправка сообщений в целевой чат
- **Telethon** – чтение сообщений из исходных чатов (использует ваш личный аккаунт)
- **python-dotenv** – управление переменными окружения
- **asyncio** – асинхронное выполнение


## 🔐 Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
# Aiogram (для отправки) – токен бота
BOT_TOKEN=ваш_токен_бота

# Telethon (для чтения) – данные вашего личного аккаунта
API_ID=ваш_api_id
API_HASH=ваш_api_hash

# Целевой чат (куда пересылать) – ID с -100 или @username
TARGET_CHANNEL=-100123456789

# Исходные чаты (откуда читать) – ID без -100 или @username, через запятую
SOURCE_CHANNELS=4359494531,@channel2

# ID администратора (для уведомлений)
ADMIN_ID=123456789
```

## ⚠️ Важно:

Telethon использует ваш личный аккаунт – он должен быть участником всех исходных чатов.

Для TARGET_CHANNEL используйте полный ID супергруппы (начинается с -100) или username.

Для SOURCE_CHANNELS используйте ID без префикса -100 (чистое число) или username.

## 🧠 Логика работы

При запуске Telethon загружает список всех диалогов (чатов, в которых состоит ваш аккаунт) и находит сущности для указанных в SOURCE_CHANNELS (по ID или username).

Регистрируется обработчик новых сообщений из найденных чатов.

При появлении нового сообщения в любом из них:

Определяется источник (username или "Unknown Source").

Если есть медиа – оно скачивается и отправляется в целевой чат вместе с текстом.

Если медиа нет – отправляется только текст с отключённым предпросмотром ссылок.

Все действия логируются, администратор получает уведомление о запуске.

## ⚠️ Важные замечания

Аккаунт для чтения – ваш личный аккаунт (Telethon) должен быть участником всех исходных чатов. Без этого чтение невозможно.

ID чатов – для супергрупп ID обычно отрицательный (например, -100123456789). В SOURCE_CHANNELS используйте число без -100 (т.е. 123456789), а в TARGET_CHANNEL – полный ID с -100.

Личные данные – никогда не храните API_ID, API_HASH и BOT_TOKEN в коде. Используйте только .env.

Лимиты Telegram – учитывайте ограничения на количество сообщений и медиа, чтобы не попасть под блокировку.
